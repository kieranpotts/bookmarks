= Email capture

sending them to real recipients.

* https://debugmail.io/[DebugMail]

* https://github.com/mailhog/MailHog[MailHog]
* https://github.com/maildev/maildev[MailDev]
* https://mailtrap.io/[MailTrap]
* https://pypi.org/project/lazr.smtptest/[lazr.smtptest]
