= AI Agents

AI agent products and chat-based assistants for research, coding, and general-
purpose tasks.

* https://www.deepseek.com/[DeepSeek]
* https://www.perplexity.ai/[Perplexity]
* https://replit.com/[Replit]
* https://claude.ai/[Claude]
* https://gemini.google.com/[Gemini]
* https://deepseek.com/harness/en/[DeepSeek Harness] – An open-source agent development framework built on the Cordis kernel, composing models, tools, storage, scheduling, and UI as interchangeable plugins.
* https://pi.dev/[Pi] – A minimal, extensible agent harness for the terminal. Customize it with extensions, skills, prompt templates, and themes; supports 15+ providers and shareable tree-structured session history.
* https://omp.sh/[omp (Oh My Pi)] – Extends Pi with enhanced capabilities.
* https://github.com/mattpocock/sandcastle[Sandcastle] – A TypeScript library for orchestrating AI coding agents in isolated sandboxes.
* https://t3.codes/[T3 Code] – An open-source GUI that orchestrates multiple AI coding agents (Claude Code, Codex, OpenCode, Cursor, and others) from one interface, using your existing subscriptions.
* https://github.com/gastownhall/beads[Beads] – A dependency-aware issue tracker that gives AI coding agents durable, structured memory in place of ad hoc markdown task lists. Built on Dolt.
* https://github.com/gastownhall/gastown[Gas Town] – A workspace manager that coordinates multiple AI coding agents (Claude Code, GitHub Copilot, Codex) and persists their work state in git-backed hooks so it survives restarts.
