than in a database.

* https://getkirby.com/[Kirby]
* https://spinalcms.com/[Spinal CMS]
* https://decapcms.org/[Decap CMS (formerly Netlify CMS)]
* https://cloudcannon.com/[CloudCannon]
* https://tina.io/[Tina CMS]
* https://statamic.com/[Statamic]
* https://frontmatter.codes/[Front Matter CMS]
