# Add bookmark

Given a URL, the agent follows the link, analyzes where it would be best
placed, and adds the bookmark.

The skill expressly instructs the agent to NOT commit the change.

## Interactivity

The agent is instructed to prompt the user to clarify the category under
which the bookmark should be filed.

## How to invoke

> Add bookmark: [url]

## Recommended models

A fast, cheap utility model will do the job just fine.
